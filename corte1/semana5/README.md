# Semana 5

## Actividad 5 - Familiarizacion con Jira

El objetivo de esta actividad fue familiarizarse con Jira como herramienta de gestion de proyectos bajo la metodologia Scrum.

Se trabajó en la creacion y organizacion de los siguientes elementos dentro del tablero:

- **Epicas:** agrupaciones de alto nivel que representan grandes funcionalidades del sistema.
- **Features:** descomposicion de las epicas en funcionalidades mas especificas y acotadas.
- **Historias de usuario (HU):** descripcion de cada funcionalidad desde la perspectiva del usuario final, siguiendo el formato "Como... quiero... para...".
- **Tareas:** unidades de trabajo concretas derivadas de cada historia de usuario.

El ejercicio practico consistio en modelar el proceso de preparacion de un ajiaco, definiendo todas sus funcionalidades como si fuera un sistema de software real.

Se logro comprender la jerarquia Epica > Feature > Historia de usuario > Tarea y como Jira organiza el backlog y el tablero Scrum para el seguimiento del proyecto.
