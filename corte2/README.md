## Cómo agregar una semana nueva

1. Crea una rama desde `develop`: `git checkout -b feature/semanaX`
2. Crea la carpeta `corte2/semanaX/` con su `README.md`
3. Agrega el código fuente en `src/main/java/dosw/bitacora/semanaX/`
4. Documenta la evidencia en el README semanal
5. Haz commit y push, luego abre un PR hacia `develop`
